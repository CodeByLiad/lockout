# .spine/config.md — pinned cross-cutting context (asserted before task one)
- Stack:            Flutter 3.47.2 / Dart 3.13.2 (SDK at C:\src\flutter, NOT on PATH — invoke C:\src\flutter\bin\flutter.bat by absolute path) + SQLite (sqflite). GPL-3.0-or-later, zero-network at runtime, native Android APK. `google_fonts` is REMOVED — it fetched typefaces over HTTP, which never resolves on an offline device. `dynamic_color` is REMOVED — the Nuvetrix house system forbids dynamic colour (§2), because wallpaper-derived schemes make a family of apps stop looking like a family. NO NEW PACKAGE DEPENDENCIES for the Expressive restyle: shape morphing and the lobed shapes are framework-only (`ShapeBorder` subclass + `Cubic` curve), not an off-the-shelf shape package.
- Test runner:      `C:\src\flutter\bin\flutter.bat test --concurrency=1` — MUST be serial. Suites share one sqflite database file, so the default parallel run produces ~10 spurious failures. Serial baseline: 671 passed at 255c7f7 (was 586 at 0a2ae73, before the Nuvetrix restyle).
- DB / project / env: sqflite SQLite local storage engine, on-device only (offline). Schema version 4, `lib/services/database_service.dart`; migrations use the idempotent add-column helper, never a destructive recreate.
  The Expressive restyle does NOT touch the schema. It changes one stored SETTING: `theme_key` moves from a single scheme key to the pair (brightness, accent). The six retired keys must migrate in `ThemeController._resolveKey`, never by clearing the setting — `graphite`→dark+steel, `paper`→light+steel, `ember`→dark+coral, `linen`→light+coral, `indigo`→dark+violet, `frost`→light+teal, `dynamic`→system+lime (Material You is gone), absent-or-junk→system+lime.
- Auth context:     None (100% offline, local device only)
- Conventions:      GOVERNING DOCUMENT: `docs/design/nuvetrix-app-design-system.md` (Nuvetrix App Design System v1.1), vendored from the canonical copy and kept byte-identical to it. It is authoritative for colour, type, shape, motion, spacing, components, copy and icons. Lockout may depart from it ONLY via a numbered entry in the deviation register of `docs/spine/specs/2026-10-07-house-rebuild-design.md` §3; anything outside that register that contradicts the house system is a contract violation. The register currently holds D1 JetBrains Mono, D2 free accents (no Pro tier), D3 Cubic curves not Compose springs, D4 `LockoutSemantics`/`categoryRamp`, D5 lobe count as register, D6 `steel` accent, D7 five nav tabs (RESOLVED, permanent — five daily destinations, Food already user-disableable), D8 no all-caps style. D9 and D10 are RETIRED: the bespoke `NvSegmentedButton` implements §5.2 segment shapes and `NvButton` reads `MediaQuery.disableAnimations` from its own context. SCREEN COMPOSITION REBUILDS FROM THE HOUSE CATALOG: house components live in `lib/widgets/house/` with an `Nv` prefix, each written in the same task as its first real consumer screen and never merged without one; a rebuilt screen composes from `lib/widgets/house/` and the theme only, never from a pre-rebuild widget in `lib/widgets/`.
  Supersedes the baseline M3 contract merged at b3eebc2, which pinned a fixed shape scale and forbade bounce; both are deliberately reversed below. Still in force from that contract: no 3px ink borders, no zero-blur hard shadows, no `JinatraTokens`, and colour/type/shape resolve through `Theme.of(context)` / `ColorScheme`, never a static token class and never a compile-time colour constant.
  SHAPE IS A STATE, NOT A CONSTANT. Every interactive surface carries a rest radius and an active (pressed or selected) radius, and animates between them: button pill→12 (large pill→16, both with a 97% scale), list row 8→20, chip 12→pill, segmented inner 8 / ends 22 / selected pill, swatch 18→26. A single fixed radius on an interactive surface is a contract violation. The HERO CARD is the exception and does NOT morph: it carries the house signature outline, 36dp on three corners and 12dp bottom-left, because a card has no pressed state. Non-interactive radii: dialog 32, sheet 32 top corners, field 16.
  CONNECTED LIST GROUPS replace uniform cards. A group is a column of rows with 3dp gaps; the first and last child carry 26dp outer corners, inner corners stay 8dp.
  LOBED SHAPES (polar-rose `CookieBorder`, lobe counts 4/6/9/12 at amplitudes .1/.07/.06/.04) appear ONLY on subject-scale elements — Today hero day marker, session-complete badge, progress hero medallion, theme swatch — where lobe count reads as register (4 rest, 6 training, 9 streak, 12 achievement). Repeated small icon containers take ONE consistent squircle; they must not rotate lobe count, because colour already carries category and two signals on one axis read as noise. Real content — text containers, images — is never clipped into a lobed shape.
  MOTION: `LockoutMotion` exposes exactly three tiers, matching the house system's three kinds by settle time. `springFast` = `Cubic(0.2, 1.35, 0.3, 1)` at 250ms for press morphs, chip selection and the switch thumb. `springDefault` = the same curve at 450ms for sheets, screen transitions and card expands. `effects` = `Curves.easeOut` at 200ms with NO overshoot, for colour and opacity. Framework `Durations`/`Easing` tokens are no longer used. Reduced motion collapses all three to an instant state change.
  TYPE: the house type scale verbatim — `displayLarge` through `labelSmall` — plus `countdown` (Bricolage 800, 88/72, -0.05em) and `numericTable` (JetBrains Mono 500, 15/22). SENTENCE CASE EVERYWHERE; there is no uppercase style. Three bundled families under `assets/fonts/`, static instances only (Flutter collapses a variable font to one instance and `fontWeight` stops working): Bricolage Grotesque = display (500/700/800, statics from `ateliertriay/bricolage`), Figtree = body (400/500/600/700, statics from `erikdkennedy/figtree`), JetBrains Mono = columnar numerals only (400/700). Space Grotesk and Inter are NOT bundled. Swapping the body face off Inter re-opens every measured layout constant — `LockoutTheme.statTileHeight = 72` first — so each is re-derived under Figtree and re-pinned at text scale 1.0 to 1.15.
  THEME MODEL: the house neutral palette with a real light/dark pair, and TWO INDEPENDENT AXES — brightness (`system|light|dark`) and accent (`lime|violet|teal|coral|steel`). Accent is NOT welded to brightness. There is no third dynamic axis. Lockout's identity accent is Rep lime `#C2EE7B` on ink `#1F2E00`, registered in the house accents table and the default on a fresh install; `gold #FFB938` is WishPlay's and must not appear. In light the accent fills `primaryContainer`/`onPrimaryContainer` while `primary` stays `#2E2766` for every accent; in dark the accent fills `primary` and `primaryContainer` alike. Custom `success`/`successContainer` roles are `#1E6E47`/`#CDEFD9` light and `#7ED3A4`/`#0F3D27` dark. The six authored schemes (graphite/ember/indigo/paper/linen/frost) retire; see the migration above. App name stays LOCKOUT.
  SPACING: 4dp base on an 8dp grid; card padding 16, screen margins 20 for text and headings and 16 for grouped lists and cards, SECTION GAP 28 (was 24), heading-to-content 12, and 128dp bottom padding on scrollable screens that carry both a nav bar and a FAB.
